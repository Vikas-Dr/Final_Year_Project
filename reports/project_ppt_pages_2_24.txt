Page 2: Project Overview

The AI-Powered Interview Evaluation & Resume Analysis System is a smart recruiting platform designed to help recruiters and evaluators review candidates more efficiently. The project reduces manual work by automatically analyzing resumes, checking candidate identity, and evaluating interview performance.

The system works in three major steps:
- Resume analysis and candidate scoring
- Identity verification through ID upload and face matching
- Interview evaluation with reports and ranking

This project is useful for HR teams, companies, and universities where large numbers of applicants need quick and fair evaluation.

Page 3: Problem Statement

Traditional hiring methods are slow and often unfair. Recruiters spend too much time reading resumes and comparing them with job requirements. In many cases, they must also check whether the candidate is real and not using fake identity details.

These problems create delays, poor decisions, and a higher chance of human error. Many companies still do manual work that can be replaced by automation.

The project solves this by using AI to automate resume analysis, identity verification, interview evaluation, and final reporting.

--------------------------------------------------
Page 4: Objectives of the Project

The main objective of this project is to make recruitment faster, smarter, and more reliable.

The project aims to:
- Analyze resumes automatically and extract important information
- Match candidate skills with the job description
- Verify the candidate using ID document and face matching
- Generate interview questions based on the job role
- Evaluate candidate performance and create reports
- Reduce manual effort and improve decision-making

This system supports both recruiters and academic evaluators who need a structured and fair evaluation process.

Page 5: Scope of the Project

The scope of this project includes all important parts of the hiring process.

The system covers:
- Resume upload and parsing

- Interview sessions with multiple question types

The project is designed to support multiple job roles and can be extended to bigger recruitment systems in the future.

Page 6: Existing System vs Proposed System

Existing System:
- Recruiters review resumes manually
- Candidate evaluation depends on human judgment
- Identity checks are often weak or missing
- Large applicant numbers slow down the process
- Reports are created manually and can be inconsistent

Proposed System:

Page 9: Resume Analysis Module

The resume analysis module reads uploaded resume files and extracts the key information. It identifies details such as:
- Candidate name
- Education details
- Work experience
- Skills and certifications
- Projects and achievements

The system then compares this information with the job description to find the candidate's compatibility. This helps recruiters understand who is best suited for the job.

Page 10: Job Matching and Scoring

After the resume is analyzed, the system calculates a job-match score. This score is based on how closely the candidate matches the required qualifications.

The system checks:
- Relevant skills
- Education qualification
- Work experience
- Domain knowledge
- Certification and project experience

A higher score means a stronger match for the role. This helps recruiters shortlist candidates based on objective data.

--------------------------------------------------
Page 11: ID Card Upload and Face Verification

One important feature of this project is identity verification. Before the candidate starts the test, they must upload an ID card and capture a live face image.

The system compares the ID image and face image to check if they belong to the same person. If the images match, the candidate is allowed to continue. If they do not match, the system blocks access.

This step reduces fake participation and improves trust in the interview process.

Page 19: Implementation Flow

The implementation starts with user login and resume upload. The backend extracts the text and identifies key details. The system then compares the resume with the job role and generates a match score.

After that, the candidate verifies identity using ID and face matching. If accepted, the system starts the interview. The answers are evaluated and final results are stored in the report system.

This workflow makes the process automatic and easy to track.
